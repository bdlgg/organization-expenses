# Система учета расходов организации

## Назначение

Приложение предназначено для учета и контроля расходов организации. Система позволяет регистрировать расходы, относить их к определенным категориям и подразделениям, а также учитывать подтверждающие документы.

## Целевая аудитория

Предполагаемые пользователи системы — сотрудники организации, ответственные за учет расходов, руководители подразделений и сотрудники бухгалтерии.

## Предметная область

Предметная область проекта — учет и контроль расходов организации. В рамках системы рассматривается информация о финансовых затратах организации, их категориях, подразделениях и документах, подтверждающих расходы.

## Основные сущности

- **Подразделение** — структурная часть организации, к которой относится расход.
- **Расход** — финансовая операция с указанием суммы, назначения и подразделения.
- **Категория** — вид расхода, например аренда, транспорт, закупки или реклама.
- **Документ** — документ, подтверждающий совершение расхода.

## Основные функции

- регистрация информации о расходе;
- определение категории расхода;
- проверка корректности суммы расхода;
- расчет итоговой суммы расхода с учетом налога.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация моделей и связей между сущностями;
- реализация пользователей, регистрации и разграничения доступа;
- реализация операций создания, просмотра, изменения и удаления данных;
- разработка REST API;
- контейнеризация приложения с использованием Docker;
- настройка CI/CD;
- разработка автоматизированных тестов.
