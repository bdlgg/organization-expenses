# Система учета расходов организации

Консольное приложение для учета расходов организации.

## Возможности

- просмотр расходов;
- добавление расходов;
- поиск расходов;
- фильтрация расходов по категории;
- сортировка расходов по сумме;
- расчет общей суммы;
- расчет средней суммы;
- просмотр статистики;
- работа с категориями;
- работа с подразделениями;
- работа с документами;
- сохранение данных в JSON.

## Структура проекта

- `main.py` – точка запуска и основное меню;
- `expenses.py` – класс Expense и функции работы с расходами;
- `categories.py` – класс Category и функции работы с категориями;
- `departments.py` – класс Department и функции работы с подразделениями;
- `documents.py` – класс Document и функции работы с документами;
- `storage.py` – сохранение и загрузка данных;
- `utils.py` – вспомогательные функции и обработка пользовательского ввода;
- `data/` – JSON-файлы данных;
- `tests/` – автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.
