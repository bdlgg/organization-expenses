# Система учета расходов организации

Консольное приложение по учёту расходов организации, дополненное базовым
веб-интерфейсом на Django в рамках практической работы № 5.

## Возможности консольной версии (ПР1–ПР3)

- просмотр расходов;
- добавление расходов;
- поиск расходов;
- фильтрация расходов по категории;
- сортировка расходов по сумме;
- расчёт общей и средней суммы расходов;
- получение статистики;
- работа с категориями, подразделениями и документами;
- сохранение и загрузка данных в JSON;
- обработка некорректного пользовательского ввода.

## Веб-интерфейс (ПР5)

Веб-интерфейс создан на Django 5.2 и отображает данные из JSON-файлов,
используя классы предметной области, разработанные на ПР3. Консольная версия
остаётся доступной через `main.py`.

Реализованные страницы:

- `/` — главная страница;
- `/expenses/` — список расходов;
- `/expenses/<int:expense_id>/` — подробная информация о расходе;
- `/categories/` — список категорий;
- `/departments/` — список подразделений;
- `/documents/` — список документов;
- неизвестный URL — собственная страница 404 при временном отключении `DEBUG`.

На ПР5 не выполняется перенос сущностей в Django ORM и не добавляются формы
создания или редактирования. JSON остаётся хранилищем предметных данных.

## Структура проекта

- `main.py` — запуск консольной версии;
- `models/` — классы `Expense`, `Category`, `Department`, `Document` и функции
  предметной логики;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы предметных данных;
- `tests/` — автоматизированные pytest-тесты;
- `manage.py` — команды управления Django;
- `org_expenses/` — настройки Django и корневая маршрутизация;
- `homepage/` — главная страница, общий HTML-каркас и обработчик 404;
- `expenses/` — страницы списка и подробной информации о расходах;
- `catalogs/` — страницы категорий, подразделений и документов.

## Используемые технологии

- Python 3.11;
- Django 5.2;
- HTML и CSS;
- Bootstrap 5.3 через CDN;
- JSON;
- pytest;
- flake8.
