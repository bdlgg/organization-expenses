# Система учета расходов организации

Консольное приложение для учета расходов организации.

## Возможности

- просмотр расходов;
- добавление расходов;
- поиск расходов;
- фильтрация по категории;
- сортировка расходов по сумме;
- расчет общей суммы;
- расчет средней суммы;
- просмотр статистики;
- сохранение данных в JSON-файл.

## Структура проекта

- main.py – основной сценарий и меню;
- expenses.py – работа с расходами;
- storage.py – загрузка и сохранение JSON;
- utils.py – вспомогательные функции и безопасный ввод;
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.
