# Работа с данными в ПР9

В ПР7 исходная SQLite-база создавалась средствами `sqlite3`. В ПР9 таблицы
целевой базы управляются миграциями Django, а представления получают данные
через Django ORM.

- `data/organization_expenses.sqlite` — исходная база ПР7, используется только
  для чтения при переносе данных;
- `db.sqlite3` — целевая база Django, создаётся командами `migrate`;
- `db/inspect_source_db.py` — просмотр структуры исходной базы;
- `db/import_sqlite_to_orm.py` — перенос записей в ORM-модели с сохранением ID
  и связей.

Из корневого каталога проекта:

```bash
python manage.py migrate
python db/inspect_source_db.py
python db/import_sqlite_to_orm.py
```

Скрипт переноса можно запускать повторно: он использует `update_or_create()` и
не дублирует записи с уже существующими первичными ключами. Изменения в целевой
базе выполняются в одной транзакции. Исходная база ПР7 не изменяется.
